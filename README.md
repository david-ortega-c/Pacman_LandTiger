
# Pacman LandTiger

This is a project made for the Computer Architectures Masters Class at Politecnico di Torino. It is made to run in a NXP 1768 LandTiger board

## Instructions

1. Download ARM Keil uVision 5 
2. Download software pack for board NXP LPC1768 
3. Open the [Project file](12_sample_GLCD_TP/12_sample_GLCD_TP/Source)
